JARVIS

JARVIS は、Web コンサルタントが自身の業務のために使う個人用の作業支援ツールです。利用者本人が管理する Google アカウントのデータを閲覧し、資料作成や日々の確認作業を補助します。一般向けのサービスではなく、配布・販売はしていません。

プライバシーポリシー

  • 取得する情報: 利用者本人が許可した Google アカウントの、Search Console・Google アナリティクス・Google タグマネージャー・Google ビジネスプロフィール・Google 広告・Gmail のデータ（いずれも閲覧のみ）。
  • 利用目的: 利用者本人の業務における分析・確認・資料作成のため。
  • 保存場所: 利用者本人が管理するパソコンの中にのみ保存します。外部のサーバーには送信・保管しません。
  • 第三者提供: 行いません。販売・共有もしません。
  • 行わない操作: メールの送信・削除・既読化、広告や各種設定の変更は行いません（そのための権限も取得しません）。
  • アクセス権の取り消し: Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、いつでも取り消せます。
  • JARVIS による Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。
